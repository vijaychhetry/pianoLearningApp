# Sideload APK

Debug build of **Kids Piano Lab** (Phase 1 Audio Lab). Not a Play Store release.

**Download:** [KidsPianoLab-debug-0.1.0.apk](./KidsPianoLab-debug-0.1.0.apk)

On GitHub, open that file and use **Download raw file**. On a phone, you can also use:

https://github.com/vijaychhetry/pianoLearningApp/raw/cursor/android-audio-lab-5032/releases/KidsPianoLab-debug-0.1.0.apk

Install it, allow **Microphone**, put the phone on the piano, tap **Start mic**, play one key.

If Android blocks the install, allow installs from the browser/Files app for this APK. Uninstall this debug app before installing a later Play Store build with the same package id (`com.vijaychhetry.kidspiano`).
