# Sideload APK

Debug build of **Kids Piano Lab**. Not a Play Store release.

**Download:** [KidsPianoLab-debug-0.4.0.apk](./KidsPianoLab-debug-0.4.0.apk)

On GitHub, open that file and use **Download raw file**. On a phone, you can also use:

https://github.com/vijaychhetry/pianoLearningApp/raw/cursor/compact-calibrate-keyboard-5032/releases/KidsPianoLab-debug-0.4.0.apk

Install it and allow **Microphone**. Uninstall the older 0.3 debug build first.

## What you should see

Landscape **Calibrate** screen: **Home** and **0/5** sit just under the status bar, then a thin full-range strip and a shorter playing keyboard. The asked key (C, then D, E, F, G) is painted red. The big letter and **Pause** sit under the keys, not under a blank cream band.

If the meter or log still matters, tap **Home** → **Audio Lab**.
