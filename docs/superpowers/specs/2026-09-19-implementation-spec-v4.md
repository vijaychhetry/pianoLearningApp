# Kids Piano Implementation Spec v4 — working copy

Canonical PDF: `docs/review/KidsPiano_Implementation_Spec_v4.pdf`

This file is the short working index for 0.5.0. The PDF is the source of truth.

**This release:** 0.5.0 “Trust the ears” on top of installed 0.4.0.

**Kept from 0.4.0:** YIN+HPS detector, existing AC-PITCH / AC-CAL / AC-DEB / AC-LEARN tests. Where those tests assert copy that v4 replaces (`Play the C key`, `Try C.`, addition gate), the tests are updated to the v4 copy deck and noted in the PR.

**Not in 0.5.0:** the 0.6.0 ladder/songs/planner and the 0.7.0 falling/memory games. Those wait until this APK has been used on the PSR-F52.

Open assumptions (defaults used): A1 age 6–8, A2 three-activity sessions (0.6.0), A3 multiplication gate + 2 s hold (this release).
